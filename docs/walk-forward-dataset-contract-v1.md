# 滚动前推数据集契约 v1

版本：`walk-forward-dataset-v1`

标签契约：`prediction-outcome-label-v1`

## 1. 目的

本契约把短期预测样本按时间构造成可重现的训练、独立校准和未来测试折次，并在任何训练或调参之前预留最终留出集。它只组织已经存在的真实预测与成熟结果，不生成预测、标签、概率或收益。

当前实现范围为股票，目标与期限严格限定为标签契约支持的 `absolute_up` / `excess_up` 和 1、5、20 个交易日。

## 2. 时点与泄漏门禁

每个纳入样本必须同时满足：

- 预测、特征快照、历史证券池成员关系和结果标签在对应截止时间可获得；
- `feature_cutoff_at <= signal_available_at`；
- 预测创建时间不晚于标签入场时间；
- 标签窗口完整落在训练、校准、测试或最终留出集自己的截止时间内；
- `label_available_at` 不晚于该分区截止时间；
- 模型预注册的标签版本和结果记录均为 `prediction-outcome-label-v1`；
- 信号发生时，资产属于当时可获得的历史市场证券池。

训练窗口按 `step_days` 向前滚动，不扩张为累计历史。训练、校准和测试之间设置显式 embargo；embargo 只增加隔离距离，不能替代上述逐样本时点检查。

同一 `event_id` 以及已解析的转载簇会形成传递闭包。一个簇只能保留在最早的一个分区；后续分区样本以 `event_cluster_cross_partition` 排除，同分区重复样本以 `duplicate_event_cluster_within_partition` 排除。转载关系只用于更保守地清除样本，不进入模型特征。

## 3. 最终留出集

最终留出集必须通过管理员接口在第一个信号产生前预注册，并冻结市场、目标、期限、信号区间、标签截止、批准人和用途：

`final_evaluation_only_not_model_selection`

最终留出样本在数据库中保存为 `sealed=true`，不进入公开数据集清单；API 只返回区间、计数、排除统计和不可逆摘要。若没有合格的最终留出样本，数据集构建失败。后续训练、自动演进和模型选择只能读取开发折次中的 `members`，不能读取 `fold_index=-1` 的密封记录。

密封是应用层和数据契约隔离，不替代数据库管理员权限管理。生产数据库管理员仍应把直接读取密封表视为最终评测操作并留痕。

## 4. 持久化与重现

`evaluation_dataset_versions` 保存完整配置、公开清单、候选数、分配数、排除统计和内容摘要；`evaluation_dataset_folds` 保存每轮边界与摘要；`evaluation_dataset_samples` 保存开发样本及排除原因，并单独密封最终留出样本。

数据集 ID 由配置、开发折次、排除项和密封留出集的规范化内容摘要生成。相同输入与相同截止时间得到相同 ID；幂等键不能绑定到不同清单。开发折次公开每个样本的预测 ID、事件簇、信号时间、预测可获得时间、特征截止、标签窗口、标签可获得时间及排除原因，可逐项审计。

## 5. 管理接口

所有接口都要求 `X-Admin-Token`，写接口还要求 `Idempotency-Key`：

- `POST /go/evaluation-holdouts`：预注册未来最终留出集；
- `GET /go/evaluation-holdouts`：查看预注册记录；
- `POST /go/evaluation-datasets`：在标签截止已经真实到达后构建数据集；
- `GET /go/evaluation-datasets`：查看公开数据集清单；
- `GET /go/evaluation-datasets/{datasetID}`：按 ID 读回公开清单。

接口不会自动选择留出日期，也不会为了满足验收而填充模拟生产样本。没有模型、预测或成熟标签时，应保持空列表或返回明确构建失败。

## 6. 已知边界

- 当前没有真实生产预测样本时，只能证明代码、迁移和门禁可用，不能声称完成了真实市场滚动评测。
- `source_lineage` 的转载簇是可更新记录；数据集一旦生成，以持久化清单为复现依据。其后新增的转载关系只能用于新版本更保守地排除样本，不得修改既有数据集。
- 最终留出评测、可解释基线训练和独立校准属于下一步骤，不能用本步骤的数据集构建成功替代效果验收。
